# Fidelizarei - Landing Page

Landing page moderna e profissional para o Fidelizarei, um SaaS de fidelização sem aplicativo.

## 🚀 Como rodar

### 1. Instalar dependências

```bash
npm install
```

### 2. Rodar dev server

```bash
npm run dev
```

A página abrirá automaticamente em `http://localhost:3000`

### 3. Build para produção

```bash
npm run build
```

Isso vai gerar a pasta `dist/` pronta para deploy.

## 📁 Estrutura

- `landing.jsx` - Componente principal da landing page
- `index.html` - HTML base
- `main.jsx` - Ponto de entrada do React
- `index.css` - Estilos Tailwind
- `vite.config.js` - Configuração do Vite
- `tailwind.config.js` - Configuração do Tailwind

## 🎨 Seções

- **Hero** - Apresentação do conceito principal
- **Como funciona** - 4 passos do processo
- **Benefícios** - 6 vantagens principais
- **Demo visual** - Carteira, QR Code e Dashboard
- **Pricing** - Plano único de R$ 79,90/mês
- **CTA** - Call to action final

## 🛠 Tecnologias

- React 18
- Tailwind CSS
- Vite
- Lucide React (ícones)

## 📝 Customização

Todos os textos, cores e conteúdo podem ser facilmente customizados editando `landing.jsx`.
